REFERENCE_LEDGER_VERSION: 1
POLICY_STATUS: REQUIRED_RELEASE_ARTIFACT
LAST_UPDATED: 2026-09-10

PURPOSE
This file records external research, standards, software architectures, and source-code projects actually consulted while designing or hardening Descendants. Every future implementation tranche that materially relies on an external idea, algorithm, data model, accessibility rule, or source-code architecture must add or update an entry here before the tranche may be treated as verified.

RESEARCH GOVERNANCE
- Record sources that materially influenced design, tests, algorithms, architecture, UI/accessibility, or validation.
- Distinguish concept adoption from code reuse. Reading source code does not authorize copying it.
- Record license/rights information when known. If rights are unclear, treat the source as REFERENCE_ONLY and do not copy code/assets/data.
- Preserve Descendants' canonical invariants: one authoritative simulation state, stable identity, explicit provenance, provider-bounded knowledge, deterministic/replayable state transitions, and renderer/UI non-authority.
- Empirical models are priors or calibration references, not universal truth. Fictional/generated worlds must remain internally coherent rather than falsely claiming empirical realism.
- A passing reference check is not evidence that a source was correctly understood; implementation tests and visual QA remain mandatory.
